# 小四數學挑戰 · P.4 Maths Quiz

一個單檔 HTML 問答遊戲，題目取材自 `Sources questions` 內四份小四數學試卷
（4001、4002、4003、4004），共 **90 題**。

開啟 `index.html` 即可遊玩 — 毋須安裝、毋須網絡、沒有任何外部連結。

---

## 遊戲功能

| | |
|---|---|
| 範疇選擇 | 全部 / 數的運算 / 因數與倍數 / 應用題 / 度量 / 圖形 / 方向 / 數據處理 |
| 題數 | 10、20、30 或全部 |
| 計分 | 答對 10 分，連擊額外加分（最高 +10），連擊斷了歸零 |
| 🏆 排行榜 | 分數打入前 10 名即可輸入名字；金銀銅獎牌、新紀錄會高亮顯示 |
| 即時回饋 | 顯示正確答案並附**解題說明** |
| 錯題回顧 | 完場後列出所有答錯的題目、你的答案、正確答案與解釋 |
| 最佳紀錄 | 以 `localStorage` 分範疇記錄最高分 |
| 操作 | 滑鼠／觸控，或鍵盤 <kbd>1</kbd>–<kbd>4</kbd> 作答、<kbd>Enter</kbd> 下一題／儲存名字 |
| 其他 | 每次隨機抽題並打亂選項次序；手機／平板／電腦自適應；內建音效（WebAudio，無音檔） |

## 關於排行榜

- **每個題數設定各有自己的排行榜**（10 題 / 20 題 / 30 題 / 全部），因為題數不同滿分也不同，分開比較才公平。
- 只保留**最高的 10 個分數**；同分時正確率高者在前，再同則較早達成者在前。
- 0 分不會獲邀請入榜。
- 可在主頁按 **🏆 排行榜** 查看，並可按題數切換；**清除紀錄** 可重設該題數的榜。
- 名字長度上限 12 字，會自動記住上次輸入的名字。

### 兩種排行榜模式

| | 本機模式（預設） | 共用模式（Google 試算表） |
|---|---|---|
| 設定 | 不用設定 | 需部署一次 Apps Script |
| 資料存放 | 瀏覽器 `localStorage` | 你的 Google 試算表 |
| 同學之間看到對方分數 | ❌ | ✅ |
| 離線可用 | ✅ | ✅（自動退回本機紀錄） |
| 費用 | 免費 | 免費 |

## 用 Google 試算表做排行榜後端

全班共用排行榜只需做一次設定，之後所有人開同一個網址就會看到同一個榜。

### 第 1 步：建立試算表

1. 開啟 <https://sheets.new> 新建一個 Google 試算表。
2. 改個名字，例如「小四數學挑戰 排行榜」。
3. **不用自己建立欄位**，程式第一次寫入時會自動建立工作表 `leaderboard` 和標題列。

### 第 2 步：貼上程式碼

1. 在試算表選 **擴充功能 → Apps Script**。
2. 刪去編輯器內原有的 `function myFunction() {}`。
3. 把本資料夾的 **`Code.gs`** 全部內容貼進去，按 💾 儲存。

### 第 3 步：部署成網頁應用程式

1. 右上角按 **部署 → 新增部署作業**。
2. 齒輪圖示選 **網頁應用程式**。
3. 設定：
   - **執行身分**：`我`
   - **誰可以存取**：`所有人`  ← 必須選這項，同學才不用登入
4. 按 **部署**，第一次會要求授權：
   選擇你的 Google 帳戶 → 「進階」→「前往〈專案名稱〉(不安全)」→ 允許。
   （因為程式是你自己寫的，未經 Google 審核，顯示此警告屬正常。）
5. 複製畫面上的 **網頁應用程式網址**，形如：

   ```
   https://script.google.com/macros/s/AKfycbx................/exec
   ```

### 第 4 步：填進遊戲

開啟 `index.html`，在檔案頂部找到這一段（約第 10 行）：

```html
window.P4_CONFIG = {
  SHEET_API: '',   // 例如：'https://script.google.com/macros/s/AKfycb..../exec'
  SHEET_KEY: ''
};
```

把網址貼進 `SHEET_API`：

```html
window.P4_CONFIG = {
  SHEET_API: 'https://script.google.com/macros/s/AKfycbx................/exec',
  SHEET_KEY: ''
};
```

儲存後重新上載到 GitHub。主頁會顯示 **☁️ 已連接共用排行榜** 即代表成功。

### 第 5 步（可選）：加一道簡單密碼

想防止別人用網址亂寫假分數：

1. 在 `Code.gs` 把 `var SECRET = '';` 改成例如 `var SECRET = 'p4maths2026';`
2. **重新部署**（部署 → 管理部署作業 → ✏️ → 版本選「新版本」→ 部署）
3. 在 `index.html` 把 `SHEET_KEY` 填上相同字串。

> 注意：網頁是公開的，密碼寫在網頁內只能擋住隨手亂試的人，不是真正的保安。
> 另外 `Code.gs` 已內建基本檢查：分數必須為正數，且不得超過「答對題數 × 20」，
> 名字會過濾角括號並限制 12 字，可擋住大部分亂寫的假成績。

### 管理資料

- 所有成績會逐行寫入試算表，你可以直接篩選、排序、做統計。
- 在 Apps Script 編輯器可手動執行：
  - `pruneSheet()` — 只保留每個題數的前 10 名，刪走其餘資料
  - `resetSheet()` — 清空所有紀錄
- 共用模式下，遊戲內的「清除紀錄」按鈕會停用（避免學生誤刪全班紀錄）。

### 運作原理

網頁以 **JSONP**（GET + `callback` 參數）呼叫 Apps Script，因此完全不需處理 CORS，
手機、平板、電腦的瀏覽器都可直接使用。流程：

```
開啟網頁        → action=list  取回 10/20/30/all 四個榜
完場且分數夠高  → action=list  再取一次最新的榜 → 顯示「輸入名字」
按儲存          → action=add   寫入試算表 → 回傳最新前 10 名 → 畫面即時更新
連線失敗        → 自動改用本機 localStorage，並顯示 ⚠️ 提示，遊戲照常可玩
```

## 上載到 GitHub Pages

只需要 **`index.html`** 一個檔案。

1. 在 GitHub 新建一個 repository（例如 `p4-maths-quiz`），勾選 *Public*。
2. 上載 `index.html` 到 repository 根目錄
   （網頁介面：**Add file → Upload files**，拖入後 **Commit changes**）。
3. 進入 **Settings → Pages**：
   - **Source** 選 `Deploy from a branch`
   - **Branch** 選 `main`、資料夾 `/ (root)`，按 **Save**。
4. 等 1–2 分鐘，網址會是：

   ```
   https://<你的帳號>.github.io/<repository 名稱>/
   ```

> 用 Git 指令的話：
> ```bash
> git init
> git add index.html
> git commit -m "Add P.4 maths quiz game"
> git branch -M main
> git remote add origin https://github.com/<你的帳號>/<repo>.git
> git push -u origin main
> ```

## 修改題目

題庫與版面是分開的，方便日後增減題目：

```
questions.js    題庫（唯一的題目來源）
template.html   版面與遊戲邏輯（包括排行榜）
build.js        把題庫注入版面，產生 index.html
Code.gs         Google Apps Script 排行榜後端（貼到試算表的 Apps Script）

_test_leaderboard.js   開發用：自動測試本機排行榜
_test_sheets.js        開發用：以本機伺服器模擬 Apps Script，測試共用排行榜
_shot.js               開發用：產生完場畫面截圖
```

> 上載到 GitHub 只需要 `index.html`；`Code.gs` 是貼到 Google Apps Script 的，不用上載。

改完 `questions.js` 後執行：

```bash
node build.js
```

就會重新產生 `index.html`。

### 題目格式

```js
{
  c:'calc',                    // 範疇 calc/num/word/measure/shape/direction/data
  s:'4001',                    // 來源試卷
  q:'25 × 32 × 4 = ?',         // 題目（可用 HTML）
  t:'<table>…</table>',        // 選填：附表
  o:['3200','320','800','2800'],// 四個選項
  a:0,                         // 正確選項的索引（0 = 第一個）
  e:'25 × 4 = 100，100 × 32 = 3200。'   // 解題說明
}
```

遊戲會自動打亂選項次序，所以 `a` 只需對應 `o` 陣列的原始位置。
